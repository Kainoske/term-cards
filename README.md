# 研究用語カード

研究で調べた専門用語の辞書。登録すると同時に単語カードになり、**分野**と**日付**で絞り込んで暗記練習できます。オフラインで動くWebアプリ（PWA）です。

## 機能
- **登録**：用語・読み/英語/略語・意味・分野・日付・出典メモ。同じ用語の重複は警告します。分野と日付は次の登録にも引き継がれます。
- **辞書**：キーワード検索、分野・日付で絞り込み、並べ替え（新しい順／五十音／苦手順）、編集・削除。
- **暗記**：分野（複数選択）と日付（1日 or 期間）で範囲を選んで出題。
  - 出題対象：すべて／今日の復習（忘却曲線に沿った復習日が来たもの）／苦手のみ
  - 表裏の向き：用語→意味／意味→用語
  - 「まだ／あいまい／覚えた」で自己採点。「まだ」はそのセッション内でもう一度出ます。
  - 復習間隔：Lv0→当日、Lv1→1日、2日、4日、7日、15日、30日後（Lv6 で習得）
  - PCではキー操作可：スペース＝裏返す、1/2/3＝採点
- **データ**：JSON/CSV書き出し、JSON読み込み（統合）、Excelからのタブ区切り一括登録、全削除。

## データの保存先
ブラウザ内（IndexedDB）にだけ保存され、外部には送信されません。端末・ブラウザごとに別々なので、移行やバックアップには「JSONで書き出す」を使ってください。

## 起動方法
`file://` で直接開くとオフライン機能が働かないため、Webサーバー経由で開きます。

- **このPCで使う**：Claude の preview（`.claude/launch.json` の `term-cards`）か、次のコマンドで起動して http://localhost:8790 を開く。
  ```
  python -m http.server 8790 --directory term-cards
  ```
  開いたら Chrome/Edge のアドレスバー右の「インストール」でアプリ化できます。
- **スマホでも使う**：公開版 https://kainoske.github.io/term-cards/ をスマホで開いて「ホーム画面に追加」（iPhoneはSafariの共有ボタン→ホーム画面に追加、AndroidはChromeのメニュー→アプリをインストール）。一度開けば以降はオフラインで動きます。

## 更新時
ファイルを変更したら `sw.js` の `VERSION` を上げてから、このフォルダで commit して `git push` すると、1〜2分で公開版（GitHub Pages）に反映されます。
